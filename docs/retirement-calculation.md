# 퇴직금 예상 정산

## 기준과 출처

- 확인일: 2026-09-16
- [고용노동부 퇴직금 계산기](https://www.moel.go.kr/retirementpayCal.do)
- [근로자퇴직급여 보장법 제8조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030452303)
- [근로자퇴직급여 보장법 제4조: 적용 대상](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030452231)

기준일은 한국 시간으로 페이지를 연 날짜이며, 마지막 근무일의 다음 날인 가상 퇴직일로 취급합니다. 기준일 당일을 제외한 직전 3개 달의 실제 달력일수를 사용합니다. 예: 2026-09-16 기준 2026-06-16~2026-09-15, 92일. 월별로 나누므로 표는 3~4행입니다.

1일 평균임금은 기간 임금과 산입 대상 상여금·연차수당의 3/12 가산액을 기간 총일수로 나눕니다. 1일 통상임금이 더 높으면 이를 적용하고, 적용 1일 임금 × 30 × 재직일수 / 365로 산정합니다. 1년 미만 근로 또는 주 평균 15시간 미만 선택 시 예상 법정 퇴직금은 0으로 표시합니다.

## 데이터와 추정 범위

- 로그인한 본인의 `work_logs`만 사용자 ID와 정확한 시작·종료일 조건으로 조회합니다. 관리자 화면에서 다른 사용자를 선택했더라도 이 페이지는 본인 기준입니다.
- 현재 연봉의 월 급여(기본급 및 고정수당 포함)는 산정기간에 속하는 날짜만 월의 달력일수로 일할 계산합니다. 추가수당은 기존 근무기록 재계산과 동일한 시간 구분을 사용합니다. 기본 일급은 중복 가산하지 않습니다.
- 급여 변경 이력·급여명세서 원본이 없으므로 확정 지급액이 아닙니다. 기록 없는 기간은 명시하고, 과거 임금 및 추가수당은 사용자가 명세서에 맞게 직접 수정할 수 있습니다.
- 상여금과 연차수당은 초기값 0이며 산입 대상액만 직접 입력합니다. 기간별 금액에 포함한 금액을 중복 산입하지 않습니다.
- 기준일을 바꾸면 기간별 직접 수정값을 초기화합니다. 화면의 수정값은 서버·프로필에 저장하지 않습니다.
- 조회 실패/진행 중에는 추정 결과를 숨깁니다. 모든 기간의 두 임금 항목을 직접 입력한 경우에만 기록 조회 없이 계산할 수 있습니다.
- 퇴직소득세, DC형 적립금·운용수익, 중간정산 및 제외기간 계산은 지원하지 않습니다. 제외기간 선택 시 결과를 숨기고 별도 산정을 안내합니다. 휴직 등의 이력이 있다면 공식 계산기 또는 회사 담당자를 통해 확인해야 합니다.
- 기존 월별 급여·이동시간 계산 로직이나 DB 스키마/RLS/Edge Function은 변경하지 않습니다.

## 검증

`pnpm test`에서 고용노동부 예제(1,080일, 92일, 임금 7,080,000원, 가산액 1,075,000원), 월초/월말/연도/윤년 경계, 통상임금 하한, 근속 1년, 잘못된 입력, 추가수당 중복 방지, 한국 시간 날짜를 확인합니다.
