# 급여 공제 계산 기준

## 소득세

- 소득세법 시행령 별표 2 **2026.2.27. 개정판**의 646개 구간을 사용한다.
- [국가법령정보센터 원문](https://www.law.go.kr/LSW/lsBylInfoP.do?bylSeq=18150115&lsiSeq=286211&efYd=20260701&directYn=Y)
- [원문 PDF](https://www.law.go.kr/LSW/flDownload.do?flSeq=164357181)
- PDF SHA-256: `ab78f130dd263b271ea5cf9c33dd9bf169641724f942f07ff2e261085444a48e`
- `scripts/extract-withholding-table.py`로 원문 표를 추출하며, `src/withholdingTable.ts`에 보관한다. 구간 단위는 천원, 세액 단위는 원이다.
- 과세 월급(비과세 제외)을 하한 이상·상한 미만 구간에 대입한다. 월 1천만원은 별도 행, 초과분은 원문 마지막 페이지의 6개 산식을 사용한다.
- 공제대상 가족 수에는 본인을 포함한다. 11명 초과는 별표 제4호대로 10명과 11명 열 차액을 추가 차감한다.
- 만 8~20세 자녀는 가족 수에도 포함하고 자녀 공제에도 적용한다. 월 공제는 1명 20,830원, 2명 45,830원, 3명부터 1명당 33,330원 추가다. 만 8세 미만 자녀는 가족 수에만 포함한다.
- 원천징수 100% 기준이다. 80%/120%, 과거 연도별 세액표, 상여금 지급대상기간별 별도 계산, 연말정산은 지원하지 않는다. 과거 월을 조회해도 이 개정판 기준 예상액을 표시한다.
- 소득세와 지방소득세는 각각 10원 미만 절사한다. 지방소득세율은 시스템 설정을 사용한다(기본 10%).

## 사회보험

- 2026년 근로자 부담 기본값: 국민연금 4.75%, 건강보험 3.595%, 장기요양은 건강보험료의 13.14%, 고용보험 0.9%.
- [국민연금공단 보험료 안내](https://www.nps.or.kr/pnsinfo/ntpsklg/getOHAF0097M0.do), [건강보험공단 2026 요율](https://edi.nhis.or.kr/portal/images/popup/20251204_pop01longdesc.html)
- 각 보험료는 10원 미만 절사한다. 장기요양은 절사한 건강보험료에 요율을 적용한다.
- 기존 시스템 설정의 잘못된 고용보험 0.93%는 불러올 때 0.9%로 보정한다. 관리자 설정 저장 시 보정값이 저장되므로 별도 DB 변경은 필요하지 않다.
- 현재 보험료 기준액은 국민연금의 경우 계약 월급, 나머지는 과세 월급이다. 신고 기준소득월액/보수월액, 상·하한, 면제, 정산내역을 연동한 실제 고지액은 아니다.
